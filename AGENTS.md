# Eternal Flowers Project

## Overview
A website for ordering eternal flowers (flores eternas). Customers can browse options, schedule orders via calendar, contact via social media links, and submit orders with text descriptions of desired elements.

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python, Flask
- **Database**: MySQL

## Project Purpose
Solves order confusion by making it easier for customers to select what they want via a web interface. Organizes the entrepreneur's order flow.

## Key Features
- Calendar for scheduling orders to specific dates
- Social media links for customer inquiries
- Text input field for orders with associated elements
