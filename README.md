# Nombre del proyecto: Eternal flowers

## ¿Qué problema resuelve?: Resuelve la confusión de pedidos, a los clientes se le facilita más pedir lo que necesitan ya que en la página están todos los medios necesarios para que elegir lo que uno quiere no sea un problema y resuelve la organización del emprendedor.

## ¿Para quién es?: Esta página está destinada para todas las personas que quieran realizar algún pedido de flores eternas o quieran cotizar precios.

## Funciones mínimas: El Calendario, para agendar los pedidos a una fecha específica. Link de redes sociales, para que el cliente pueda comunicarse con el emprendedor en el caso de que tenga alguna duda o consulta. Un cuadro de texto, en el que el cliente pueda escribir el pedido que gusta realizar con sus respectivos elementos.

## Stack tecnológico: HTML, CSS, JavaScript, Python, Flask, MySQL
